# Obsidian_QuickMDLinks

The Quick Link Plugin allows you to quickly create Markdown links to notes in Obsidian. You can trigger the link creation process using a command, a context menu option (right-click), or a hotkey.

Once activated, a file selection window appears, allowing you to choose the target note. The selected file is then linked to the highlighted text without changing its visible content—only the link is applied. This makes it easy to reference other notes while keeping the original text intact.
